模型接入

填一次就能用。密钥只存在这台电脑的浏览器里，不会同步到其他设备。

填到 /v1 即可，程序会自动补 /chat/completions；填完整地址也能识别。

密钥以明文保存在本机扩展存储中。建议单独申请一个低额度 Key 专供本插件使用。

越低越稳定保守，查知识建议 0.2~0.4。

多轮追问时，发给模型的全部内容（含历史压缩摘要）不超过这个量。模型窗口小就调低，窗口大想多带历史就调高。改动立即生效。

测试会真实发起一次极短的模型请求，能同时验证地址、密钥、模型名。

交互方式

控制气泡什么时候出现、回答时默认做什么。

回答统一在右侧对话面板里展开：全高显示、消息按轮次累积、可继续追问。面板宽度拖左侧边缘即可调整，会自动记住。

记录与存档

每段问答都能留在本地，随时导出成 Markdown 笔记。

超出后自动淘汰最旧的记录，被收藏的永不淘汰。

笔记集成

把面板上的单条回答，或历史里的整批存档，推进你的笔记库。内容从本机直接发往你配置的目标，不经过任何中转服务器。

填写 Obsidian 里「打开库」时显示的名字（区分大小写）。留空则由 Obsidian 自己决定写进哪个库。

库内的相对路径，不存在会自动创建。留空 = 写在库根目录。观察库根目录堆满文件的人建议填一个。

到 notion.so/my-integrations 新建一个「内部集成」，把生成的令牌复制过来。和 API Key 一样只保存在本机。

每批导出会在该页面下新建一个子页面。可以直接粘贴页面链接，ID 会自动提取。 务必把那个页面分享给集成（页面右上角 ··· → 连接 → 选中你的集成），否则会报「找不到页面」。

站点权限

只会向「接口地址」所在的域名申请联网权限，不会申请全站访问权。

若测试时提示未授权，点此处重新授权。

安全说明

  • 密钥存放位置：本机浏览器扩展存储（chrome.storage.local），明文保存，不会同步到你的其他设备，也不会发送给除你指定模型服务商以外的任何一方，更不经过任何中转服务器。
  • 页面内容：只有你主动划词并提问时，选中的文字、所在段落与页面标题才会发给你配置的模型服务商。不提问就什么都不会发出去。
  • 建议：给本插件单独申请一个低额度 Key，万一泄露损失可控。
  • 不支持：浏览器内置 PDF 阅读器、chrome:// 内部页面（浏览器不允许扩展在这些页面运行）。
